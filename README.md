# BB Visual Novel Engine

**Русский** · [English](README.en.md) · [История изменений](CHANGELOG.md)

Расширение для SillyTavern: варианты действий как в визуальной новелле, отношения с персонажами, воспоминания и боковая панель HUD.

> Эта страница описывает ветку **VNE-TEST**. Новые возможности пока не перенесены в `main`. Номер в manifest остаётся `3.1.0 Release`; изменения тестовой ветки перечислены в разделе Unreleased.

## Быстрый старт

1. В SillyTavern откройте **Расширения → Установить расширение** и укажите `https://github.com/maxkara14/BB-Visual-Novel-Engine`. Обычная установка использует основную ветку; для возможностей этой страницы нужен checkout `VNE-TEST`.
2. Обновите страницу и откройте настройки **BB Visual Novel Engine**.
3. В **Подключение для генерации** выберите текущее подключение SillyTavern, сохранённый профиль Connection Manager или своё API. Оно общее для вариантов ответа, описаний и черт характера.
4. Выберите язык интерфейса и язык новых ответов. После смены языка интерфейса обновите страницу.
5. Откройте чат, дождитесь ответа персонажа и нажмите **Действия VN**.

Формат ответа оставьте **Auto**. Настройки в разделе **Дополнительно** обычно менять не нужно.

## Как выбирать действия

Расширение запрашивает три разных варианта. Кнопка показывает намерение, а при включённой настройке — тон и краткий прогноз последствия. Иногда модель возвращает только два пригодных варианта: расширение покажет их с уведомлением.

- **Автоотправка выключена:** выбранная реплика появляется в поле ввода. Её можно прочитать, отредактировать и отправить самостоятельно.
- **Автоотправка включена:** выбранная реплика отправляется сразу. Это режим игры без предварительного просмотра, условный «хард-мод». По умолчанию автоотправка включена.

Есть повторная генерация, пожелание к вариантам через **Запрос**, автоматический показ вариантов и три длины ответа. При смене чата, персоны или исходного сообщения устаревший результат генерации не применяется.

## Отношения и память

- Боковая панель с карточками персонажей, аватарами и описаниями.
- Отдельные шкалы доверия и романтики; влияние событий можно настроить отдельно для каждой.
- Мягкие следы, незабываемые события и архив воспоминаний.
- Создание постоянных черт характера из глубоких воспоминаний.
- Журнал изменений и дневник событий.
- Переименование, скрытие и восстановление персонажей; платонический режим.

Трекер отношений можно отключить, оставив варианты действий. Для ручного размещения инструкции трекера предусмотрен макрос `{{bb_vn}}`.

В раскрытой карточке доступен блок **«Из чего складываются отношения»**: основа из чата или снимка, поправки, фактические изменения и итог отдельно для доверия и романтики. Суммарный эффект учитывает границы шкал и активные свайпы; ноль может означать взаимную компенсацию событий.

## Навигация по персонажам

Над карточками доступны поиск по имени, сортировка по доверию (выше/ниже), романтике или имени и компактный вид. Поиск скрывает карточки, не удаляя персонажей и не сбрасывая введённый в редактор текст. Сортировка и компактный вид сохраняются, поиск сбрасывается при смене чата или персоны. Сводные значения панели относятся ко всем персонажам, счётчик поиска — к найденным.

## Редактор памяти и черт

В раскрытой карточке откройте **«Редактор памяти и черт»**, выберите запись, измените текст и нажмите «Сохранить текст». Доступны мягкие и глубокие воспоминания, архив и черты текущей сцены. Для черты используйте «Название: описание» (до 240 символов), для воспоминания — до 2000 символов.

«Удалить запись» скрывает её из памяти, передаваемой модели; исходное событие, баллы и журнал сохраняются. Удалённая запись остаётся в списке редактора для отмены. «Отменить правку записи» последовательно возвращает до 20 последних изменений выбранной записи, в том числе после перезагрузки страницы.

Правки привязаны к персоне и исходной записи активного свайпа либо импортированной основы. При смене сцены незавершённое действие отменяется. Пересчёт по-прежнему определяет доступные записи: редактор не возвращает автоматически воспоминания, вытесненные из ограниченной памяти. Удаление черты не отменяет её прежнюю кристаллизацию и не возвращает использованные воспоминания из архива. Экспорт содержит отредактированное видимое состояние без истории отмены.

## Подключение и языки

| Настройка | Что делает |
| --- | --- |
| Текущее подключение SillyTavern | Использует основную модель чата для генераций расширения. |
| Профиль Connection Manager | Берёт модель и параметры из профиля, не переключая основное подключение чата. Connection Manager должен быть включён. |
| Своё API | Прямое OpenAI-compatible подключение: URL, ключ и модель. Кнопка «Подключиться» загружает список моделей через `/models`. |
| Язык интерфейса | Auto / Русский / English. Auto следует языку SillyTavern, затем браузера. Для остальных языков интерфейса используется English. |
| Язык новых ответов | Как в чате / Русский / English. Не зависит от языка интерфейса. |

Все служебные инструкции написаны на английском. Язык результата относится к новым репликам, подписям вариантов, профилям, чертам и текстовым полям отношений. Сохранённые имена и игровые записи автоматически не переводятся. Подробнее: [языки](docs/languages.md).

Разрешение использовать резервную основную модель при сбое своего API — отдельная настройка, по умолчанию выключенная. Резервный запрос не запускается при отмене, неверном ключе, квоте или блокировке провайдером.

## Дополнительные настройки

JSON — внутренняя упаковка текста кнопок и реплик. Разбираться в ней для обычной игры не нужно.

| Режим | Когда используется |
| --- | --- |
| Auto | Рекомендуемый вариант. Для основного подключения и профиля — инструкции; для своего API — схема с упрощением только при подтверждённой несовместимости. |
| JSON Schema | Явный запрос структурированного ответа. Требует поддержки со стороны подключения и модели. |
| JSON mode | Только для прямого своего API, поддерживающего `json_object`. |
| Только инструкции | Просит модель оформить JSON без специального параметра API. |

Тайм-аут одного запроса — 120 секунд по умолчанию, диапазон 15–600. Для генерации вариантов разрешены до трёх дополнительных запросов по умолчанию (можно поставить 0–5). Это общий бюджет для упрощения формата, резервной модели, исправления, дополнения и разнообразия вариантов.

Для своего API в «Дополнительно» доступен **Лимит токенов ответа**: `0` сохраняет прежний автоматический бюджет (не меньше 4000), вручную можно задать 256–131072. Значение передаётся как `max_tokens` для каждого запроса вариантов, описаний и черт; основной источник и профиль сохраняют свои лимиты. У модели может быть меньший допустимый предел. Рассуждения могут расходовать тот же бюджет, что и итоговый текст.

## Где хранятся данные

Настройки, выбранное подключение и ключ своего API сохраняются в настройках расширений SillyTavern. Игровые данные находятся в метаданных чата и сообщений: они учитывают активную персону и свайпы.

Экспорт снимка содержит отношения, воспоминания, черты, профили и аватары, журнал и дневник. Настройки подключения и API-ключ в него не включаются. При передаче снимка другому человеку учитывайте, что он содержит игровые записи и описания.

## Снимки состояния: перенос и восстановление

1. Нажмите **Экспорт**, чтобы сохранить текущую базу активной персоны в JSON-файл.
2. В целевом чате выберите нужную персону и нажмите **Импорт**.
3. Проверьте сводку: имя файла, исходную и активную персоны, формат и количество записей. Подтвердите замену.

Импорт **заменяет**, а не объединяет базу активной персоны. Сообщения чата не заменяются. События до точки импорта не прибавляются к снимку повторно; новые события и помеченные повторные генерации продолжают учитываться.

**Убрать импортированную основу** возвращает базу, сохранённую перед первым импортом, и снова пересчитывает текущую историю чата. Это не откат сообщений к прошлому моменту. Повторные импорты сохраняют первоначальную точку восстановления до очистки базы.

Поддерживаются снимок VNE версии 1 и старый объект данных с `characters` без обёртки. Неизвестные версии, файлы другого расширения, неверные типы и файлы больше 20 МиБ отклоняются до изменения базы. Дополнительно ограничены вложенность и число записей. Если во время подтверждения меняется чат или персона, выберите файл заново. Формат snapshot v2 из стороннего форка не импортируется автоматически.

В настройках показаны статус импорта и время его выполнения. Для старых импортов без даты указано «время неизвестно». Удаление основы требует подтверждения: диалог объясняет пересчёт и наличие точки восстановления. При смене чата, персоны или импорта во время подтверждения действие отменяется.

## Если что-то не работает

| Симптом | Что проверить |
| --- | --- |
| Нет профилей | Включён ли Connection Manager; нажмите «Обновить профили». |
| Профиль удалён | Выберите существующий профиль. Расширение не подменяет его другой моделью молча. |
| Неверный ключ / нет доступа | URL, API-ключ и доступ к выбранной модели. |
| Квота или ограничение частоты | Лимиты провайдера; повторите позже. |
| Тайм-аут | Доступность модели; при необходимости увеличьте время ожидания. |
| Неподдерживаемый JSON | Верните Auto или выберите «Только инструкции». |
| Пустой или обрезанный ответ | Уменьшите длину ответа или проверьте лимит токенов модели. Пустой ответ не отправляется на бессмысленное исправление. |
| Снимок отклонён | Формат VNE v1, структура и размер файла. Оригинальная база остаётся на месте. |

Подробная диагностика выключена по умолчанию. При её включении в консоль могут попадать фрагменты ответа модели — проверьте их перед публикацией отчёта.

### Постоянные пожелания к вариантам

В настройках VNE можно сохранить пожелания к стилю и содержанию вариантов (до 4000 символов). Они действуют во всех чатах при следующих генерациях; уже показанные варианты не меняются. Разовая подсказка имеет приоритет при противоречии. Обязательные формат, язык и длина ответа сохраняются, контекст Scene Director передаётся как прежде. Пожелания не добавляются к генерации профилей и черт. Кнопка «Очистить пожелания» отключает их для следующих запросов.

### Объём контекста вариантов

В разделе «Язык и ответы» настройка «Сообщений в контексте вариантов» выбирает последние 1–100 сообщений (по умолчанию 10). Считаются записи чата, а не пары реплик; в коротком чате берётся вся доступная история. Последний ответ дополнительно остаётся ориентиром сцены. Изменение применяется к следующей генерации и не удаляет историю.

Это размер блока истории VNE, а не общий бюджет входных токенов и не лимит ответа. Персона, заметка автора и сводка продолжают подставляться через макросы; контекст Scene Director сохраняется. Профили персонажей, память и отношения не добавляются отдельной копией в этот блок. Основное подключение может получить их через обычный контекст Tavern, инъекцию VNE или макрос {{bb_vn}}. Профиль подключения и своё API получают собранный промпт; полный контекст Tavern к ним автоматически не переносится. Настройка не ограничивает дополнительные данные пресета и макросов.

### Отключение вариантов

Кнопка «Выключить» внутри «Действий VN» скрывает всю панель вместе с заголовком. Вернуть её можно в настройках VNE → «Игра» → «Варианты VN». Настройка общая и сохраняется после перезагрузки. Текущий запрос отменяется, очередь автогенерации очищается; отношения, память и служебная генерация профилей/черт остаются доступны. Сохранённые варианты не удаляются. Включение возвращает панель без нового запроса; автопоказ возобновляется со следующего ответа персонажа.
