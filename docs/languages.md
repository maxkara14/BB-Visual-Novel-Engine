# Языки VNE

В настройках расширения есть два независимых выбора:

- **Язык интерфейса**: Auto / Русский / English. Auto использует выбранный язык SillyTavern, затем браузера; для языков, отличных от русского, используется английский. После изменения обновите страницу, чтобы язык применился ко всем панелям. Страница не перезагружается автоматически, чтобы не потерять незавершённое редактирование.
- **Язык новых ответов**: Как в чате / Русский / English. Применяется к новым вариантам, профилям, чертам и текстовым полям отношений. «Как в чате» передаёт модели последние реплики как ориентир языка; служебные инструкции при этом всегда английские.

Сохранённые имена, реплики, описания, воспоминания, черты и записи журнала не переводятся. Поэтому в английском интерфейсе могут оставаться русские игровые записи. Основные правила отношений, последствия выбора и автоотправка не меняются.

## Для разработки

- `language.js` формирует инструкцию о языке результата, независимо от UI. В операциях VN настройка фиксируется вместе с контекстом операции.
- `i18n.js` и `locales/en.js` переводят только принадлежащие расширению статические надписи. Русские исходные надписи служат ключами и запасным вариантом.
- `t()` разрешён для статических строк или гарантированно встроенных названий. Не передавать в него произвольный пользовательский текст.
- Тег `ui` переводит статические части шаблона до вставки значений. Экранирование HTML остаётся обязанностью вызывающего кода; перевод не заменяет `escapeHtml`.
- `template` / `templateText` предназначены для нового локального шаблона профиля. Они учитывают язык результата; для режима «Как в чате» локальный шаблон ориентируется на кириллицу в последней реплике. Генерация моделью использует инструкцию и контекст, а не эту эвристику.
- Старые русские и новые английские обозначения эмоциональных тонов распознаются одной логикой. Исходное сохранённое значение тона не переписывается.

Автоматические проверки: `node --experimental-vm-modules --test tests/generation-context.test.mjs`. Живые модели могут по-разному соблюдать языковые инструкции; проверки транспорта используют подменённые API.
