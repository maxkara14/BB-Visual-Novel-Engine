## А. Короткий контроль интерфейса

Это небольшой повтор после последних правок, а не повтор всего предыдущего списка.

- [ ] **Настройки RU/EN.** Раскрыть и закрыть все шесть разделов, проверить узкую панель. Заголовки переведены, кнопки помещаются, анимация не оставляет обрезанный контент. Вернуть предпочитаемый язык.
- [ ] **Выключение.** Открыть «Действия VN», нажать «Выключить». Панель уходит вниз с затуханием; в ряду инструментов перед меню ввода остаётся только маленькая кнопка VN, ровная относительно соседей. Проверить расположение с Enhance Gen, если он установлен.
- [ ] **Возврат.** Нажать VN. Панель появляется сдвигом вверх, кнопка возврата исчезает, новый запрос не запускается. Сохранённые варианты доступны; текст в поле ввода не теряется.
- [ ] **Повторные клики.** Быстро выключить и включить через настройки несколько раз. Итог соответствует последнему действию, нет зависшего прозрачного блока или двух активных панелей. При системном уменьшении движения переходы мгновенные; если режим недоступен, отметить пропуск.
- [ ] **Перезагрузка и автопоказ.** Выключить варианты, обновить страницу и получить ответ персонажа: остаётся VN, автоматического запроса нет; отношения и память работают. Включить — запроса ещё нет. Следующий ответ персонажа запускает варианты, только если автопоказ включён.
- [ ] **Во время запроса.** Запустить генерацию, выключить варианты через «Игра» до её завершения. Поздний результат не возвращает панель и не подменяет сохранённый набор. Вернуть VN и убедиться, что ручная генерация работает.
- [ ] **Пожелания и история.** В «Язык и ответы» задать короткое постоянное пожелание и число сообщений 3, обновить страницу: оба значения сохранены. Сгенерировать варианты с SD, если используешь его: текущая сцена сохраняется. Число сообщений ограничивает блок истории VNE, не весь контекст Tavern и не лимит ответа. Вернуть обычные значения.

## 7. Форматы и ошибки — дополнительные проверки

Не нужно искать все возможные сервисы. Начни со своих моделей. Неподдерживаемый режим сам по себе не является поломкой расширения: важны понятная ошибка и возможность продолжить после смены настройки.

| Формат | Где проверять | Ожидаемый результат |
| --- | --- | --- |
| Auto | На каждом своём источнике | Пригодные варианты; для основного подключения и профиля схема принудительно не требуется. |
| Только инструкции | На каждом своём источнике | Пригодные варианты либо понятная ошибка, если модель не справилась с форматом. |
| JSON Schema | На модели и подключении с поддержкой схем | Успешная генерация; без поддержки допустима явная ошибка. |
| JSON mode | Только своё API с поддержкой этого режима | Успешная генерация; без поддержки допустима явная ошибка. |

- [ ] **Совместимость Auto.** Если есть своё API, которое явно отклоняет схему, но поддерживает более простой режим, сравни Schema и Auto.
  Ожидается: Schema сообщает ошибку, Auto пробует более простой формат в пределах бюджета. Если такого API нет, отметь пропуск: успех на модели со схемой не проверяет автоматический переход.
- [ ] **Ошибка ключа.** Только для своего тестового API временно укажи заведомо неверный ключ и запусти генерацию.
  Ожидается: ошибка доступа, без зависания и без запроса к резервной модели даже при разрешённом резерве. После возврата ключа генерация снова работает.
- [ ] **Тайм-аут.** Если есть медленная модель, поставь 15 секунд и попробуй генерацию.
  Ожидается: запрос, который длится дольше лимита, завершается сообщением о тайм-ауте. Поздний ответ не применяется. Если модель успела ответить, тайм-аут не проверен. После опыта верни 120 секунд.
- [ ] **Лимит попыток.** Поставь дополнительные запросы 0 и сгенерируй варианты, затем верни 3.
  Ожидается: с нулём остаётся начальный запрос, без запросов исправления, дополнения и резервной модели. Если есть журнал запросов, проверь количество там; по числу уведомлений его надёжно не определить.

- [ ] **Лимит своего API.** В «Дополнительно» поставь лимит токенов ответа 16384, обнови страницу и проверь сохранение. Выполни генерацию. Если доступен просмотр отправленного запроса, проверь `max_tokens: 16384`. Верни 0 для прежнего автоматического бюджета. Успех с увеличенным лимитом не доказывает, что прежний бюджет исчерпали именно рассуждения.

## Как записывать проблему

Скопируй шаблон для каждого сбоя:

```text
Пункт проверки:
Версия/коммит VNE и версия SillyTavern:
Браузер:
Источник: основное / профиль / своё API
Провайдер и модель:
Формат: Auto / Schema / JSON mode / инструкции
Язык интерфейса и результата:
Что нажал, по шагам:
Что ожидал:
Что получилось:
Повторяется: всегда / иногда / один раз
Точный текст ошибки или скриншот:
```

Не прикладывай API-ключи. Подробную диагностику включай только для воспроизведения конкретной проблемы, затем выключай; фрагменты ответа могут содержать текст переписки.
