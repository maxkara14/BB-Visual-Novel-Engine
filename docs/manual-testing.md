# Финальная ручная проверка перед 3.2.0

Статус: ожидает финального прохода. Ветка — VNE-TEST. Проверяется актуальная VNE-TEST с генерацией портретов; коммит запишите перед проходом. Релиз отложен до полной проверки портретов. Версия в manifest пока 3.1.0 Release, это не номер нового выпуска.

## Новая функция: портреты — проверить полностью

Подключение и порядок работы: [инструкция RU/EN](portraits.md).

- [ ] Нажать «Подключить»: список загружен, модель выбирается без ручного ввода; неверный ключ не даёт успешный статус. Изменить адрес во время загрузки: старые модели не подставляются.
- [ ] Сохранить два именованных профиля и переключиться между ними: адрес, ключ и модель восстановлены, общий стиль сохранён. Проверить ручной ID как запасной вариант.
- [ ] OpenAI Images: один и несколько референсов отправляются в `/images/edits` как файлы; при недоступном endpoint видна ошибка без повторной генерации без референсов. Для Naistera встроенный список не обозначается как проверенное подключение.
- [ ] Настроить отдельное подключение в «Изображения»; проверить сохранение после перезагрузки и сохранность прежнего текстового подключения.
- [ ] В редакторе нажать «Создать»: окно помещается на обычном и узком экране, кнопки читаются; повторить на RU и EN.
- [ ] Написать ручной промпт, сгенерировать: выполняется только запрос изображения. Старый аватар до применения не меняется.
- [ ] «Собрать промпт»: текстовый запрос использует несохранённое описание нужного персонажа; результат английский даже при русском языке ответов. Проверить героя, у которого нет собственной карточки SillyTavern: чужая внешность не подмешивается.
- [ ] Общий стиль сохраняется и применяется к следующему портрету. Индивидуальный промпт можно исправить перед генерацией.
- [ ] Проверить свой используемый протокол: OpenAI Images / OpenAI Chat / Gemini / Naistera. Записать сервис, модель и пропуски. Наличие адаптера не означает поддержку любой модели.
- [ ] Добавить референс внешности, референс стиля и текущий аватар; удалить лишний. Пятый файл и неподдерживаемый формат отклоняются.
- [ ] При отказе провайдера принимать референсы появляется ошибка, запроса без референсов автоматически нет.
- [ ] Проверить неверный ключ, пустой ответ, неверный адрес и отмену/тайм-аут. Нет бесконечной загрузки; можно повторить запрос.
- [ ] Первая генерация успешна, следующая завершилась ошибкой: предыдущий портрет остаётся доступен.
- [ ] Закрыть окно без применения: прежний аватар сохранён. «Использовать» → кадрирование → сохранение → перезагрузка: новый аватар остался. Обычная загрузка и очистка аватара тоже работают.
- [ ] Во время запроса сменить чат/персону/свайп, если интерфейс позволяет, либо закрыть окно и перейти в другой чат: поздний ответ не попадает в чужую карточку.
- [ ] Экспортировать и импортировать снимок с портретом: изображение и кадрирование восстановлены; ключа API изображений и временных референсов в снимке нет.

## А. Короткий контроль интерфейса

Это небольшой повтор после последних правок, а не повтор всего предыдущего списка.

- [ ] **Настройки RU/EN.** Раскрыть и закрыть все шесть разделов, проверить узкую панель. Заголовки переведены, кнопки помещаются, анимация не оставляет обрезанный контент. Вернуть предпочитаемый язык.
- [ ] **Выключение.** Открыть «Действия VN», нажать «Выключить». Панель уходит вниз с затуханием; в ряду инструментов перед меню ввода остаётся только маленькая кнопка VN, ровная относительно соседей. Проверить расположение с Enhance Gen, если он установлен.
- [ ] **Возврат.** Нажать VN. Панель появляется сдвигом вверх, кнопка возврата исчезает, новый запрос не запускается. Сохранённые варианты доступны; текст в поле ввода не теряется.
- [ ] **Повторные клики.** Быстро выключить и включить через настройки несколько раз. Итог соответствует последнему действию, нет зависшего прозрачного блока или двух активных панелей. При системном уменьшении движения переходы мгновенные; если режим недоступен, отметить пропуск.
- [ ] **Перезагрузка и автопоказ.** Выключить варианты, обновить страницу и получить ответ персонажа: остаётся VN, автоматического запроса нет; отношения и память работают. Включить — запроса ещё нет. Следующий ответ персонажа запускает варианты, только если автопоказ включён.
- [ ] **Во время запроса.** Запустить генерацию, выключить варианты через «Игра» до её завершения. Поздний результат не возвращает панель и не подменяет сохранённый набор. Вернуть VN и убедиться, что ручная генерация работает.
- [ ] **Пожелания и история.** В «Язык и ответы» задать короткое постоянное пожелание и число сообщений 3, обновить страницу: оба значения сохранены. Сгенерировать варианты с SD, если используешь его: текущая сцена сохраняется. Число сообщений ограничивает блок истории VNE, не весь контекст Tavern и не лимит ответа. Вернуть обычные значения.

## 7. Форматы и ошибки — дополнительные проверки

Не нужно искать все возможные сервисы. Начни со своих моделей. Неподдерживаемый режим сам по себе не является поломкой расширения: важны понятная ошибка и возможность продолжить после смены настройки.

| Формат | Где проверять | Ожидаемый результат |
| --- | --- | --- |
| Auto | На каждом своём источнике | Пригодные варианты; для основного подключения и профиля схема принудительно не требуется. |
| Только инструкции | На каждом своём источнике | Пригодные варианты либо понятная ошибка, если модель не справилась с форматом. |
| JSON Schema | На модели и подключении с поддержкой схем | Успешная генерация; без поддержки допустима явная ошибка. |
| JSON mode | Только своё API с поддержкой этого режима | Успешная генерация; без поддержки допустима явная ошибка. |

- [ ] **Совместимость Auto.** Если есть своё API, которое явно отклоняет схему, но поддерживает более простой режим, сравни Schema и Auto.
  Ожидается: Schema сообщает ошибку, Auto пробует более простой формат в пределах бюджета. Если такого API нет, отметь пропуск: успех на модели со схемой не проверяет автоматический переход.
- [ ] **Ошибка ключа.** Только для своего тестового API временно укажи заведомо неверный ключ и запусти генерацию.
  Ожидается: ошибка доступа, без зависания и без запроса к резервной модели даже при разрешённом резерве. После возврата ключа генерация снова работает.
- [ ] **Тайм-аут.** Если есть медленная модель, поставь 15 секунд и попробуй генерацию.
  Ожидается: запрос, который длится дольше лимита, завершается сообщением о тайм-ауте. Поздний ответ не применяется. Если модель успела ответить, тайм-аут не проверен. После опыта верни 120 секунд.
- [ ] **Лимит попыток.** Поставь дополнительные запросы 0 и сгенерируй варианты, затем верни 3.
  Ожидается: с нулём остаётся начальный запрос, без запросов исправления, дополнения и резервной модели. Если есть журнал запросов, проверь количество там; по числу уведомлений его надёжно не определить.

- [ ] **Лимит своего API.** В «Дополнительно» поставь лимит токенов ответа 16384, обнови страницу и проверь сохранение. Выполни генерацию. Если доступен просмотр отправленного запроса, проверь `max_tokens: 16384`. Верни 0 для прежнего автоматического бюджета. Успех с увеличенным лимитом не доказывает, что прежний бюджет исчерпали именно рассуждения.

## Как записывать проблему

Скопируй шаблон для каждого сбоя:

```text
Пункт проверки:
Версия/коммит VNE и версия SillyTavern:
Браузер:
Источник: основное / профиль / своё API
Провайдер и модель:
Формат: Auto / Schema / JSON mode / инструкции
Язык интерфейса и результата:
Что нажал, по шагам:
Что ожидал:
Что получилось:
Повторяется: всегда / иногда / один раз
Точный текст ошибки или скриншот:
```

Не прикладывай API-ключи. Подробную диагностику включай только для воспроизведения конкретной проблемы, затем выключай; фрагменты ответа могут содержать текст переписки.

### Действия профилей изображений

- [ ] «Обновить выбранный» меняет только выбранный профиль; «Сохранить как новый…» запрашивает имя и оставляет старый профиль.
- [ ] Отмена ввода имени ничего не создаёт. Удаление показывает имя и требует подтверждения; отказ ничего не удаляет.
- [ ] После удаления текущее подключение сохранено; без выбранного профиля обновление и удаление недоступны.

### Галерея портретов — новый проход

- [ ] Открой «Портреты» в редакторе персонажа. Без истории активна «Создать». Сгенерируй два портрета, не применяя их, закрой окно и открой снова: активна «Галерея», оба результата доступны, старый аватар не изменён.
- [ ] Выбирай миниатюры: большой предпросмотр соответствует выбору. «Использовать» открывает кадрирование; только сохранение редактора меняет карточку.
- [ ] «Скачать» сохраняет исходную картинку до кадрирования. «Копировать изображение» позволяет вставить PNG в графический редактор. При запрете буфера показано сообщение и доступно скачивание. Проверь обе вкладки.
- [ ] После обновления страницы история сохранена. Другой персонаж, персона и другой чат имеют свою историю; возврат восстанавливает нужные записи.
- [ ] Смена чата/персоны или закрытие окна во время запроса не применяет поздний результат к чужой карточке или галерее.
- [ ] Отказ в подтверждении удаления сохраняет запись. Подтверждение убирает миниатюру, но не меняет аватар; файл остаётся на сервере. Последнюю запись тоже можно удалить.
- [ ] Если файл недоступен, показана ошибка, запись можно удалить. Если сохранение нового результата не удалось, показано предупреждение, результат можно скачать или применить. Если эти условия не воспроизводились, отметь пропуск.
- [ ] RU/EN и узкое окно: вкладки, сетка миниатюр, предпросмотр и подписи кнопок не перекрываются, окно прокручивается, выделение выбранной картинки заметно.
- [ ] Учтено: галерея не входит в снимок VNE; для резервной копии нужны метаданные чата и файлы изображений SillyTavern. Старые генерации автоматически не добавляются.

### Скрытые персонажи — новый проход

- [ ] Скрой двух персонажей: в отношениях доступна кнопка «Скрытые · 2». Если скрыты все персонажи, кнопка остаётся доступной.
- [ ] Открой список, проверь поиск (включая пустой результат) и длинные имена на узком экране.
- [ ] Верни одного: его карточка появилась с прежними отношениями, памятью и портретом; другой остался скрыт. Окно не закрылось.
- [ ] «Вернуть всех» восстанавливает всех, включая не попавших в поиск. Пустой список показывает сообщение, массовая кнопка отключена.
- [ ] Кнопка в настройках открывает это же окно и сама ничего не восстанавливает.
- [ ] После перезагрузки состояние сохранено. Действие из окна, открытого до смены чата или персоны, отклоняется с сообщением.
- [ ] Проверь RU/EN, закрытие кнопкой и Escape; имя с длинным текстом не выталкивает кнопку за границы.

### Промпт описания персонажа — новый проход

- [ ] В «Язык и ответы» раскрой «Промпт описания персонажа»: виден стандартный английский текст, его можно редактировать.
- [ ] Введи свою инструкцию (например, кратко описать внешность одним абзацем), обнови страницу: инструкция сохранена. «По шаблону» использует её; обычные варианты и портреты работают как прежде.
- [ ] Проверь другой персонаж: инструкция общая, но имя и источники относятся к выбранному персонажу. Язык результата соответствует настройке языка.
- [ ] Уже сохранённое описание не меняется от редактирования настройки. Новый результат применяется через прежний редактор.
- [ ] «Восстановить стандартный» возвращает исходный текст и сохраняется после перезагрузки. Пустое поле тоже использует стандартный промпт.
- [ ] Проверь RU/EN и узкую панель: поле и кнопка не выходят за границы.
